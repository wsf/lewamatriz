# Lewa Matriz

Sitio estático que documenta el proceso de creación de la **Matriz de diagnóstico de Santa Fe y Rosario**.

## Contenido

- propósito y alcance territorial;
- cronología del proceso de elaboración;
- método común de ocho bloques;
- diez ejes temáticos;
- reglas de trazabilidad y tratamiento de vacíos;
- documento Word final para descarga;
- transición del diagnóstico a la formulación de propuestas.

## Desarrollo local

No requiere compilación ni dependencias. Puede abrirse `index.html` directamente o servirse con cualquier servidor HTTP estático.

```bash
python3 -m http.server 8000
```

## GitHub Pages

En GitHub, abrir `Settings → Pages`, seleccionar `Deploy from a branch`, elegir la rama `main` y la carpeta `/ (root)`.

## Fuente

El contenido se basa en la versión completada de la matriz con fecha de corte 23 de octubre de 2026.
