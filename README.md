# Lewa Matriz

Sitio estático que documenta el proceso de creación de la **Matriz de diagnóstico de Santa Fe y Rosario**.

## Contenido

- proceso de construcción de la matriz;
- método común de ocho bloques;
- diez ejes temáticos;
- reglas de comparabilidad territorial;
- criterio de evidencia y fuentes prioritarias;
- documento Word final para descarga.

## Publicación

El repositorio está preparado para GitHub Pages desde la rama `main` y la raíz `/`.

## Desarrollo local

Abrir `index.html` directamente o servir el directorio con cualquier servidor HTTP estático.
